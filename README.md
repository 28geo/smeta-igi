# Смета ИГИ

Веб-приложение для расчётов инженерно-геологических изысканий.
Нормативная база: приказ Минстроя России от 12.05.2025 № 281/пр.

Откройте опубликованный сайт или index.html в браузере.
Расчёты и хранение проектов выполняются в браузере. Для переноса сметы
используйте сохранение и открытие JSON. Сметы не отправляются на сервер.

В репозитории размещаются только приложение и нормативная база;
рабочие сметы, резервные копии, EXE и локальные документы сюда не входят.
